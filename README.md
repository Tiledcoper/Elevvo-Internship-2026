# Elevvo Internship 2026

This repository contains the projects I completed during my Elevvo Internship 2026.

## Projects

### Task 1 — Student Score Prediction
A regression project for predicting students' Performance Index using academic and study-related features.

**Tools:** Python, Pandas, NumPy, Matplotlib, Scikit-learn

[Open Task 1](./Task%201/)

### Task 2 — Customer Segmentation
A customer segmentation project using Annual Income and Spending Score. I used K-Means clustering and also tested DBSCAN as a bonus.

**Tools:** Python, Pandas, Matplotlib, Scikit-learn

[Open Task 2](./Task%202/)

### Task 8 — GTSDB Traffic Sign Recognition
A YOLOv8-based traffic sign detection project using the German Traffic Sign Detection Benchmark (GTSDB).

The project includes training, evaluation, image prediction, webcam inference, FPS benchmarking, and ONNX export.

**Tools:** Python, YOLOv8, PyTorch, OpenCV, ONNX, CUDA

[Open Task 8](./Task%208/)

### Task 10 — Traffic Sign Recognition API
An MLOps deployment project based on the Task 8 model. The trained YOLOv8 model is served through a FastAPI API and can also be used through a Streamlit frontend.

The project also includes Docker, automated tests, Postman, and GitHub Actions.

**Tools:** FastAPI, YOLOv8, Docker, Streamlit, Pytest, GitHub Actions

[Open Task 10](./Task%2010/)
